# Design: Canonical minimal-DI example (starlette rollout)

## Summary

Ship a canonical, runnable example in `modern-di-starlette`: a minimal
`examples/` app wiring one `Settings` (APP scope) and one `GreetingService`
(REQUEST scope) into a route handler via the real `@inject` + `FromDI` idiom,
an in-memory smoke test that proves it runs, and the README `Usage example:`
line. This is a rollout of the locked pattern piloted in
`modern-di-faststream` (see its
`planning/changes/2026-07-24.01-canonical-example-onramp.md`), adapted to
starlette's own idiom: `@inject` + `FromDI` (there is no `Depends`), verified
with `starlette.testclient.TestClient`.

## Motivation

The [blessed-ready on-ramp audit](https://github.com/modern-python/modern-di/blob/main/planning/audits/2026-07-22-blessed-ready-onramp-report.md)
found this repo, like 9 other integrations, at D2=1 (complete inline README
example, no dedicated linked example) / D6=1 (no `Usage example:` line).
faststream piloted the fix; this change rolls the same shape into starlette.

## Design

**The example** — `examples/app.py` (+ `examples/__init__.py`): the smallest
runnable starlette app that demonstrates the recommended wiring, matching the
README snippet's shape but as a complete program:

- `Settings` — `providers.Factory(scope=Scope.APP, creator=Settings)`.
- `GreetingService` — `providers.Factory(scope=Scope.REQUEST, ...)`, depends
  on `Settings` by type (auto-injected).
- one `@inject`-decorated route handler taking the service via
  `typing.Annotated[GreetingService, FromDI(Dependencies.service)]`, wired by
  `setup_di(app, container)`. A `# run: uvicorn examples.app:app` header
  comment states how to run it for real.

Diverges from the README snippet only for testability: the endpoint takes a
path parameter (`/greet/{name}`) and returns a `JSONResponse` embedding the
service's real output, so the smoke test can assert on it directly instead of
a static payload.

**Smoke test** — `tests/test_example.py`: imports the example's `app` and,
using the repo's existing in-memory idiom (`starlette.testclient.TestClient`,
already used across `tests/test_routes.py` et al.), issues one GET request and
asserts the injected `GreetingService`'s real greeting comes back. This proves
the example runs with no infra and keeps it from rotting.

**Coverage** — none excluded. The smoke test executes `examples/app.py` end to
end (import wires the app + route; the request runs the handler), so it covers
the example to 100% under the repo's existing `--cov-fail-under=100` gate. No
`omit` needed and no unreachable boot line to mark `# pragma: no cover` — the
module has no `if __name__ == "__main__":` block.

**README** — insert `Usage example: [examples/](./examples)` directly under
the `Full guide:` line, matching faststream's placement.

**Lint posture** — add `CPY001` (no per-file copyright header) to
`[tool.ruff.lint] ignore`, matching the pilot; the example files carry no
license header.

No `modern_di_starlette/` source changes, so no `architecture/` promotion —
this adds documentation-grade example + test, not a capability change.

## Non-goals

- A realistic/DB starter — minimal DI demo only, per the locked pattern.
- New runtime dependencies — the example uses only `starlette` + `modern-di`,
  already present.
- Editing the inline README snippet or any integration behavior.

## Testing

- `just test-ci` green: the smoke test covers `examples/app.py` to 100% (no
  exclusion) and asserts a real (not mocked) resolved-service response.
- `just lint-ci` green (ruff/ty/eof/format over the new files).
- `just check-planning` green (this bundle validates).
- Manual sanity: `uvicorn examples.app:app` starts and `curl
  localhost:8000/greet/world` returns `{"greeting": "Hello, world!"}`
  (documented, not a CI gate).

## Risk

- **Example rot** (low x low) — mitigated structurally: the example is
  measured (no coverage exclusion) and the smoke test executes it every CI
  run, so a broken or uncovered example fails the build.
- **Example drifts from the README snippet** (low x low) — they share one
  shape; keep the example the runnable superset of the snippet.
